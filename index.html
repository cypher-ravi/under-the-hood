    Design questions

    Interview problems, worked step by step

    High-level questions follow the same interview steps: requirements, core entities, API, high-level design, then deep dives, with the design drawn live and grown one component at a time. Low-level questions go from requirements to a class diagram, design patterns, a step-through of the objects at work and runnable code. The step order follows Hello Interview's delivery framework.

        DSA patterns

        Grouped by data structure

        Learn the pattern, not the problem. Each page explains the idea from first principles, how to spot it in a question, and a template. Then every problem shows the question visually and steps through the answer one line of code at a time, with inputs you can change. The pattern-first structure is inspired by Codeintuition.

        AI lessons

        From zero, one concept at a time

        A course in AI for software engineers who are new to machine learning. Each lesson teaches one idea: the intuition first, then the mechanics with every symbol defined, then a small worked example by hand and in Python, with a diagram or a widget that computes real values.

        Every topic, question, pattern and lesson is one self-contained HTML file. No build step.
