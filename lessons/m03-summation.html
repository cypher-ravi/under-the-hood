M03 · Summation (Σ) and averages

The big Greek Σ looks scary, but it is a for-loop you already write every week: start a total at zero, walk through a list, add one thing each time. Divide that total by how many things you added and you have an average, the number behind every "mean error" a model reports.

a · Where this is usedLessons that lean on Σ

Lesson 03 · A model is a function (total squared error, and the average 22.8 as the best constant guess) and Lesson 06 · Probability basics (the expected value E[X] = Σ x · P(X = x)). Coming next: Lesson 07 · Loss functions (coming), Lesson 09 · Linear regression (coming) and Lesson 14 · Evaluation metrics (coming), which all start with "add this up over every example, then divide".

b · Why this mattersEvery loss is a sum

A model is never judged on one example. It makes a guess for every row in the data, gets a miss on each, and the training loop needs one number to push down. That number is almost always "add up the misses, then divide by how many there were", written in papers as (1/n) Σ (yᵢ − ŷᵢ)². If you can read that line as a loop, half of the formulas in ML stop being decoration.

c · The intuitionA shopping receipt and a shared bill

A supermarket receipt is a sum. The till goes down the list of items one at a time and keeps a running total; the last line is everything added together. Nobody needs a formula for that. Σ is only a short way to write down the instruction "go down the list and keep a running total".

Now five friends split a dinner bill. One ate a lot, one only had soup. The fair share is the total divided by five: everyone pays the same amount, and the bill is still covered. That fair share is the average (also called the mean). The friends who ate more than the fair share make up for the ones who ate less, exactly, to the rupee. Hold on to that "they cancel out" feeling; it is why the average is called a balance point.

d · How it actually worksFrom a list to Σ to the average, in seven steps

1. Adding a list, the long way

Lesson 03 had five flats with monthly rents (in thousands of rupees) of 14, 19, 22, 28 and 31. The total is

14 + 19 + 22 + 28 + 31 = 114

Fine for five numbers. For 50,000 training examples we cannot write every term, and we want one line that works for any list. That needs two small tools: names for the items, and a symbol for "add them all".

2. Naming the items: subscripts

Call the list y and number its items from 1. The small number written low after the letter is a subscript, and it just says "which one":

y₁ = 14, y₂ = 19, y₃ = 22, y₄ = 28, y₅ = 31

Read y₃ as "y sub three" or "the third y". It is exactly y[3] in code, except that maths usually counts from 1 where Python counts from 0. When we don't want to say which item, we write yᵢ, "the i-th y", where i stands for any position. The length of the list gets its own letter, n; here n = 5.

3. The Σ sign: a for-loop on paper

Σ is the capital Greek letter sigma, the Greek S, for Sum. Here is the total rent written with it, next to the same thing in Python:

Maths
5Σi=1yᵢ = 114
  • i=1 below: start the counter at 1
  • 5 on top: stop after i = 5
  • yᵢ on the right: what to add each time
Python
# pad so y[1] is the first item
y = [None, 14, 19, 22, 28, 31]
n = 5
total = 0
for i in range(1, n + 1):  # 1..5
    total += y[i]
print(total)               # 114
Σ, "sum" (capital sigma)
Add up the expression on its right, once for every value of the counter. In code: total = 0, then a loop of total += …. The starting zero is built in: Σ never starts from anything else.
i, the index
The loop counter. It is a placeholder: Σ yᵢ and Σ yⱼ mean the same thing, just as renaming i to j in a loop changes nothing.
The start (below) and the stop (on top)
Where the counter begins and the last value it takes, both included. i = 1 to 5 runs through 1, 2, 3, 4, 5: five terms. Python's range(1, n + 1) needs the + 1 because range stops just before its end.
The expression (on the right)
The loop body: the thing computed and added on each pass. It may be just yᵢ, or something built from it like yᵢ².
Shortcuts you'll see
When the range is "every item", books often drop it and write Σᵢ yᵢ or just Σ y. Read it as sum(y).

4. Sums of expressions

The expression on the right can be any calculation. Each pass, you compute it for the current i and add the result. Two you will meet constantly:

  • Σ xᵢ²: square each item, then add the squares. For the areas x = 4, 6, 8, 10, 12 that is 16 + 36 + 64 + 100 + 144 = 360.
  • Σ (yᵢ − ŷᵢ)²: the total squared error from Lesson 03. Here yᵢ is the true rent of flat i and ŷᵢ ("y-hat i") is the model's guess for it. The loop body is "miss, squared".

With the guess ŷ = 2x + 6, flat by flat:

5. Three handy rules, and why they are true

Because a sum is only repeated addition, a few shortcuts follow from ordinary arithmetic. Each one is checked here with the areas x = 4, 6, 8, 10, 12, where Σ xᵢ = 40.

Rule 1 · Pull a constant out
Σ c·xᵢ = c · Σ xᵢ

Why: every term carries the same factor c, so factor it out once: 2·4 + 2·6 + … = 2·(4 + 6 + …).
Check: 8 + 12 + 16 + 20 + 24 = 80 = 2 × 40

Rule 2 · A constant, added n times
Σ c = n · c

Why: the loop body ignores i, so every pass adds the same c.
Check: 6 + 6 + 6 + 6 + 6 = 5 × 6 = 30

Rule 3 · Split a sum
Σ (aᵢ + bᵢ) = Σ aᵢ + Σ bᵢ

Why: addition doesn't care about order, so regroup: all the a's first, then all the b's.
Check: Σ (2xᵢ + 6) = 80 + 30 = 110

Check the last one the slow way: the guesses 2xᵢ + 6 are 14, 18, 22, 26, 30, which add to 110. Same answer, and with the rules we never wrote the five guesses out. In code terms, the split rule says one loop doing two additions equals two loops doing one each.

What does not work: pulling a square or a product out. Σ xᵢ² = 360, but (Σ xᵢ)² = 40² = 1600. "Square, then add" and "add, then square" are different loops.

6. The mean: total divided by count

ȳ = (1/n) · nΣi=1yᵢ = 114 / 5 = 22.8
ȳ, "y-bar", the mean
The average of the y's: add them up, divide by how many. A bar over a letter is the usual way to write "the average of".
(1/n) · Σ
"Average over all items." Multiplying by 1/n is the same as dividing by n; by rule 1 it could sit inside or outside the Σ.

Fair share. If all five flats charged the same rent and the landlords' total income stayed 114, each would charge 22.8. That is what the mean means: the one value that, used for everyone, gives the same total.

Balance point. Measure each rent's distance from the mean: −8.8, −3.8, −0.8, +5.2, +8.2. The ones below add to 13.4, the ones above add to 13.4. They cancel exactly, always, for any list. The rules from step 5 prove it in one line:

Σ (yᵢ − ȳ) = Σ yᵢ − n·ȳ = 114 − 5 × 22.8 = 0

(Split the sum, then the constant ȳ added n times is n·ȳ, which is the total by definition.) Put the five rents on a ruler as equal weights and the ruler balances on a pivot at 22.8. That is the picture in the lab below.

The best constant guess. Lesson 03 said that if a model must guess one number for every flat, the best is the average. Try it: the total squared error Σ (yᵢ − c)² is 190 for c = 22, 187 for c = 23, and 186.8 for c = 22.8, the lowest. Any other c leaves the misses unbalanced and pays for it. Lesson 05's slopes can prove this in general; for now, the numbers show it.

Mean squared error. Average the squared misses instead of adding them and you get the mean squared error, MSE: (1/n) Σ (yᵢ − ŷᵢ)² = 6 / 5 = 1.2. Same information as the total, but it doesn't grow just because you have more rows, so 1.2 on 5 flats and on 5,000 flats can be compared. This is the loss of Lesson 07.

7. The weighted average, and why E[X] is one

The plain mean treats every item the same. Sometimes items should count for different amounts. Say homework counts for 40% of a grade and the exam for 60%, and you scored 80 and 70. The plain average is 75, but the grade is 0.4 × 80 + 0.6 × 70 = 32 + 42 = 74: the exam pulls harder.

weighted average = Σ wᵢ·xᵢ / Σ wᵢ
wᵢ, the weight of item i
How much item i counts. Weights can't be negative. When they already add up to 1 (like 0.4 and 0.6), the bottom Σ wᵢ is 1 and you can leave it off.
The plain mean is a special case
Give every item weight 1/n: the weights add to 1 and Σ (1/n)·xᵢ is exactly the mean.

Now look again at Lesson 06's expected value, E[X] = Σ x · P(X = x). It is a weighted average where the weights are probabilities, which always add up to 1. The "!" counts of Lesson 06 took the values 0 to 5 with probabilities 0.25, 0.25, 0.125, 0.125, 0.125, 0.125, so

E[X] = 0×0.25 + 1×0.25 + 2×0.125 + 3×0.125 + 4×0.125 + 5×0.125 = 2

A fair die gives every face weight 1/6, so its E[X] is the plain average of 1 to 6, 3.5. The loaded die that shows 6 half the time gives the 6 a heavier weight and the balance point slides up to 4.5. Same Σ, different weights.

e · See itReading the symbol, then running the loop

Σ unroller: watch the loop run

Pick what to add, edit the numbers if you like, then step through the loop. Each step computes one term and adds it to the running total. The number line shows the items with a pivot at their average so far: the pulls on either side always match.

i – this term – running total 0 mean = total / n –

Numbers are separated by commas or spaces, 1 to 10 of them. Every default here is a number used elsewhere on this page: Σ rents 114 and mean 22.8, Σ areas² 360, squared misses 6 and MSE 1.2, and the "!" expected value 2.

Things to try. Step through the rents and watch the pivot settle on 22.8, with 13.4 pulling each way. Switch to the squared misses: the total is 6 and the mean, 1.2, is the MSE. In the weighted mode, change the weight of 5 to a large number and see the balance point slide right, the way the loaded die's expected value moved from 3.5 to 4.5. Then set all six weights equal: the weighted average becomes the plain average, 2.5.

f · Worked exampleBy hand, then in Python

The data. Lesson 03's five flats: areas x = 4, 6, 8, 10, 12 (hundreds of sq ft) and rents y = 14, 19, 22, 28, 31 (₹ thousands), n = 5.

  • Σ yᵢ = 14 + 19 + 22 + 28 + 31 = 114, running totals 14, 33, 55, 83, 114.
  • ȳ = 114 / 5 = 22.8. Distances from it: −8.8, −3.8, −0.8, +5.2, +8.2; below adds to 13.4, above adds to 13.4.
  • Guesses ŷᵢ = 2xᵢ + 6: 14, 18, 22, 26, 30. Squared misses 0, 1, 0, 4, 1. Σ (yᵢ − ŷᵢ)² = 6, so MSE = 6 / 5 = 1.2.
  • Rules: Σ 2xᵢ = 2 · 40 = 80. Σ (2xᵢ + 6) = 80 + 5·6 = 110. And Σ xᵢ² = 360 ≠ (Σ xᵢ)² = 1600.
  • Best constant: Σ (yᵢ − c)² is 190 at c = 22, 186.8 at c = 22.8, 187 at c = 23.
  • Weighted: probabilities 0.25, 0.25, 0.125, 0.125, 0.125, 0.125 add to 1, and Σ x · P(x) = 2.
# Lesson 03's five flats: x = area in hundreds of sq ft, y = rent in thousands of rupees
x = [4, 6, 8, 10, 12]
y = [14, 19, 22, 28, 31]
n = len(y)

# Σ yᵢ as a loop. The math counts i from 1; Python lists count from 0, so y[i - 1]
total = 0
for i in range(1, n + 1):
    total += y[i - 1]
print(total)                                   # 114

# the same sum, built in
print(sum(y))                                  # 114

# the mean: Σ yᵢ / n
mean = sum(y) / n
print(mean)                                    # 22.8

# balance point: the distances from the mean cancel out
dev = [round(v - mean, 1) for v in y]
below = -sum(d for d in dev if d < 0)
above = sum(d for d in dev if d > 0)
print(dev)                     # [-8.8, -3.8, -0.8, 5.2, 8.2]
print(round(below, 1), round(above, 1))        # 13.4 13.4

# a sum of an expression: squared misses of the guess ŷ = 2x + 6
y_hat = [2 * xi + 6 for xi in x]
print(y_hat)                                   # [14, 18, 22, 26, 30]
sq = [(yi - yh) ** 2 for yi, yh in zip(y, y_hat)]
print(sq, sum(sq), sum(sq) / n)                # [0, 1, 0, 4, 1] 6 1.2

# the rules, checked with numbers
print(sum(2 * xi for xi in x), 2 * sum(x))                 # 80 80
print(sum(2 * xi + 6 for xi in x), 2 * sum(x) + 6 * n)     # 110 110
print(sum(xi ** 2 for xi in x), sum(x) ** 2)               # 360 1600

# the average is the best constant guess
for c in (22, 22.8, 23):
    print(c, round(sum((yi - c) ** 2 for yi in y), 2))
# 22 190
# 22.8 186.8
# 23 187

# a weighted average with probabilities as weights is an expected value
values = [0, 1, 2, 3, 4, 5]
probs = [0.25, 0.25, 0.125, 0.125, 0.125, 0.125]
print(sum(probs), sum(p * v for p, v in zip(probs, values)))   # 1.0 2.0

In real code you will almost always write sum(...) (or numpy's .sum() and .mean()), not the explicit loop. But when a paper shows a Σ, the loop is what it means, and writing it out once is the fastest way to check you've read it right.

g · Common misconceptionsThree things that sound right but aren't

"Σ xᵢ² is the same as (Σ xᵢ)²."The brackets say which happens first. Σ xᵢ² squares each item and then adds: 360 for our areas. (Σ xᵢ)² adds first and squares the total once: 1600. The pull-out rule only works for a plain constant factor, never for a square.
"Σ of a constant is just that constant."The loop still runs n times. Σ from i = 1 to 5 of 6 is 6 + 6 + 6 + 6 + 6 = 30, not 6. Forgetting this is how the + 6·n goes missing when people split Σ (2xᵢ + 6).
"The average is a typical value from the data."No flat rents for 22.8, and no die rolls 3.5. The mean is a balance point, not a member of the list, and one extreme value drags it a long way: change the 31 to 131 and the mean jumps from 22.8 to 42.8, above four of the five rents.

h · Check yourselfThree quick questions

1. Unroll and compute 4Σi=2(2i). How many terms are there?

Show answer

The counter runs i = 2, 3, 4 (start and stop both included), so three terms: 2·2 + 2·3 + 2·4 = 4 + 6 + 8 = 18. In Python: sum(2 * i for i in range(2, 5)). Note the expression can use i itself, not only a list item.

2. For the areas x = 4, 6, 8, 10, 12 you know Σ xᵢ = 40. Without adding five numbers, find Σ (3xᵢ − 1).

Show answer

Split, then pull out the 3, then the constant runs 5 times: 3 · 40 − 5 · 1 = 120 − 5 = 115. Check the long way: 11 + 17 + 23 + 29 + 35 = 115.

3. Lesson 03's first guess, ŷ = 3x, had squared misses 4, 1, 4, 4, 25. Write its mean squared error with Σ and compute it.

Show answer

MSE = (1/5) Σ (yᵢ − ŷᵢ)² = (4 + 1 + 4 + 4 + 25) / 5 = 38 / 5 = 7.6. The second guess had MSE 1.2, so it is better by the same factor as the totals, 38 versus 6. Put 14, 19, 22, 28, 31 and 12, 18, 24, 30, 36 into the lab's squared-misses mode to check.

i · The one-line takeawayIf you remember one thing

Σ is a for-loop that adds one term per item; divide that total by the count and you get the mean, the balance point where the items above and below cancel out.
